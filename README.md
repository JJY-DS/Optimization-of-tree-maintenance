# Optimization of tree maintenance
## OBJECTIVE:  The main objective of the Project is to optimize tree maintenance in Paris.

METHODOLOGY: Tree maintenance can be optimized if we concentrate on the growth of trees i.e. the development stage of trees. Young trees need maximum care, Young adults like adolescents need to be shaped. Trees in Adult phase need no care. Mature trees need to be checked for base. The growth parameters for trees are circumference and height (used in our analysis). Increasing circumference tells us about the development stage of tree. On analysing these parameters, we can plan and optimize the number of visits for tree maintenance. 

SUMMARY OF WORK DONE: 
After exploratory data analysis, I analysed that there are two growth parameters for trees (circumference and height). These can be used for getting the life stages of a tree. As the  focus was on optimizing tree maintenance, so descriptive statistical analysis was done. After removal of outliers and binning of data according to circumference, visualizations were created to show the regions with number of trees classified in various growth stages. Analysis helps in planning the visits in specific domains by tree count according to the development stages (J, JA, A, M) e.g. domain alignment has 16802 trees in J and 20503 trees in JA. So, visits and staff can be planned accordingly for care of these young trees. For optimizing visits for a particular tree type, analysis of exact number of trees in different domains can be used e.g. 4751 Platanus trees in J development stage are present in domain alignment and 6407 Platanus are in JA development stage. These values can be effectively used for planning visits.
